# Reference Speaker Crossfeed FIRs

These FIRs implement the `reference` crossfeed preset. They are generated by
`generate-firs.py` and loaded by CamillaDSP from `/etc/camilladsp/reference-speaker/`.

Design assumptions:

- stereo speakers at +/-30 degrees
- 48 kHz processing
- adult head radius of 8.75 cm
- Brown/Duda one-pole/one-zero spherical-head shadow model
- Woodworth-style interaural delay, about 0.261 ms at 30 degrees
- no generic pinna notches or room reflections
- phantom-center compensation, so dual-mono/center content remains tonally flat

The compensation is deliberate. A raw speaker-to-ear matrix is geometrically
closer to loudspeakers, but centered stereo material develops a deep comb notch
and bass/lower-mid lift when rendered directly into earbuds. The checked-in FIRs
preserve the near-ear/far-ear cues while normalizing the center response that
most stereo mixes rely on.
